# Seminario Completo – Observatorio Regional de Nariño

Plataforma académica de análisis económico y competitividad municipal.

**Autores:** Camila Guerrero · Geovanny Betancourt

## Módulos
- Mapa coroplético real de Colombia (divisiones político-administrativas DANE MGN 2018)
- Visualización 3D de competitividad municipal
- Estadística descriptiva + gráficos
- Econometría (correlaciones + OLS)
- Modelo VAR con funciones de impulso-respuesta (IRF) interactivas
- Modelos predictivos a 2030
- Asistente temático

## Despliegue en Netlify
1. Sube el contenido de esta carpeta a la raíz de un repositorio GitHub.
2. Publish directory: `.`
3. Deploy.
